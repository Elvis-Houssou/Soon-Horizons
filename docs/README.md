## Comment lire ces documents

Les descriptions sont tirées du code et des fichiers de consignes du dépôt, notamment `AGENTS.md`, `CLAUDE.md`, `package.json` et les fichiers sous `src/`.

Les contenus d'exemple du site (projets, chiffres, coordonnées et identité de l'architecte) sont explicitement signalés comme fictifs/provisoires dans le code. Ils ne doivent pas être présentés comme des références réelles.

Cette documentation ne constitue pas un audit d'exécution : aucun build, test automatisé ou parcours navigateur n'a été exécuté dans cet environnement.
